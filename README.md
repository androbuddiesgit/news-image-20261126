## How it was made

The front page — masthead, dateline, four illustrated stories, headlines,
captions and footer briefs — is drawn deterministically with Pillow. The
panel illustrations are flat shapes drawn for this page (no photos, no
network, no randomness), so every word is exactly legible. No fact in the
image is invented: every number, name and outcome above comes from the
listed sources.
